## ✨ Features at a Glance

- 📝 **Rich WYSIWYG Drafting Canvas**: Instant headings, bold, italic, code blocks, blockquotes, and non-destructive highlights.
- ⚡ **Notion-Style Slash Commands (`/`)**: Keyboard-first block insertion without ever touching the mouse.
- 🎯 **Zen Mode Focus View (`Ctrl + Shift + F`)**: Clean, distraction-free fullscreen writing experience.
- 🎙️ **Real-Time Speech Dictation**: Zero-latency voice-to-text with interim speech feedback ribbons.
- 📂 **Multi-Workspace Management**: Organize documents into separate vaults with drag-and-drop workspace transfer.
- 🗂️ **Native HTML5 Drag & Drop**: Fluid card reordering and direct drag-to-workspace or drag-to-trash capabilities.
- 🗑️ **Isolated Soft-Delete Trash Bin**: Safe note lifecycle with complete recovery and permanent wipe options.
- 🔍 **Spotlight Command Palette (`Ctrl + K` / `Cmd + K`)**: Instant search and system actions at the speed of thought.
- 💾 **Vault Backup & Disaster Recovery**: One-click complete vault export & import via standardized JSON payloads.
- 📄 **Clean PDF Export Engine**: Tailored print stylesheets producing crisp, borderless, high-contrast document PDFs.
- 🌗 **Precision Dual Theme**: Void Amethyst Dark Mode & High-Contrast Light Mode with hardware-accelerated scroll styling.

## ⌨️ Productivity Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `Ctrl + K` / `Cmd + K` | Toggle Spotlight Command Palette |
| `Ctrl + Shift + F` | Toggle Zen / Focus Mode |
| `/` | Trigger Notion-style Slash Command Menu |
| `Arrow Up` / `Arrow Down` | Navigate notes directly from the stream |
| `Ctrl + Z` / `Ctrl + Y` | Document Undo & Redo History |
| `Escape` | Dismiss modals, popovers, and search palettes |

## 🛠️ Tech Stack

- **Framework**: React (Fast Refresh, Hooks, Modular Memoization)
- **Bundler**: Vite
- **Styling**: Tailwind CSS, Hardware-Accelerated Gradients & Keyframes
- **Icons**: Lucide React
- **Persistence**: Safe `localStorage` syncing with JSON Schema validation

## 🚀 Getting Started

Clone the repository and spin up your local development vault in seconds:

```bash
# 1. Clone the repository
git clone [https://github.com/MuhammadSaim54/Aetheris-Pro.git](https://github.com/MuhammadSaim54/Aetheris-Pro.git)

# 2. Navigate into the project folder
cd aetheris

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
